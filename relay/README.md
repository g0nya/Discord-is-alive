# Отчёты DiscordLink в Telegram

Cloudflare Worker принимает отчёты по HTTPS и отправляет сообщение только в настроенный чат Telegram. В отчёте есть версия, название профиля, тип сбоя и результаты публичных проверок с задержками. Текст ошибок, токены, данные аккаунтов, содержимое трафика и идентификаторы пользователей не отправляются. Cloudflare использует IP запроса для ограничения частоты. IP не включается в текст сообщения.

## Публикация

1. Создайте бота у [BotFather](https://t.me/BotFather). Напишите своему боту `/start`. Для личного чата используйте числовой `message.chat.id` из ответа [getUpdates](https://core.telegram.org/bots/api#getupdates).
2. Из этой папки войдите в свой аккаунт Cloudflare и опубликуйте Worker.

   ```sh
   npx wrangler@4 login
   npx wrangler@4 deploy
   npx wrangler@4 secret put TELEGRAM_BOT_TOKEN
   npx wrangler@4 secret put TELEGRAM_CHAT_ID
   npx wrangler@4 secret put RELAY_KEY
   ```

3. Введите токен, ID чата и отдельный ключ приёма в соответствующих запросах Wrangler. Для ключа используйте, например, `openssl rand -hex 32`. Токен Telegram храните только в секретах Cloudflare. Если идентификаторы `namespace_id` заняты другими лимитами вашего аккаунта, задайте свои уникальные значения в `wrangler.toml`.

## Подключение приложения

Скопируйте `telemetry.example.json` рядом с `DiscordLink.exe` как `telemetry.json`. Укажите опубликованный адрес Worker с путём `/v1/report` и ключ `RELAY_KEY`. Файл с реальным ключом передавайте только тем, кому разрешаете отправлять отчёты. Не добавляйте его в репозиторий или публичный релиз.

В главном меню нажмите `9` и подтвердите отправку. Пункт `9` также отключает отчёты. Согласие относится к конкретному адресу и ключу. По умолчанию отправка выключена. Успешный отчёт отправляется не чаще одного раза в день с локальной установки, сбой — не чаще раза в час. Для доставки Worker должен быть доступен из сети пользователя.

При первой настройке запустите DiscordLink на Windows с настроенным файлом и проверьте, что в чат пришло сообщение. Локальная проверка маршрутизации и формата обработчика выполняется командой `node --test worker.test.mjs`.
