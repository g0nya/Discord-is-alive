# DiscordLink

Портативная утилита для Discord и YouTube на Windows 10/11 x64. DiscordLink выбирает профиль обхода DPI, проверяет доступ к сервисам и восстанавливает подключение после смены сети или выхода из сна.

## Запуск

1. Скачайте `DiscordLink.exe` или ZIP в разделе **Assets** на [странице последнего релиза](https://github.com/g0nya/Discord-is-alive/releases/latest). Если используете ZIP, распакуйте его.
2. Закройте другие обходы на базе `winws.exe` и запустите `DiscordLink.exe`. Подтвердите запрос Windows на повышение прав, чтобы WinDivert мог обрабатывать сетевые пакеты.
3. Откроется главное меню, а в области уведомлений появится значок DiscordLink. Когда проверки пройдут, полностью закройте и заново откройте Discord. Для проверки YouTube откройте видео.

При первом запуске программа скачивает [официальный ZIP Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3) и сверяет опубликованный SHA-256. Если GitHub недоступен, положите сам официальный `zapret-discord-youtube-1.10.3.zip` рядом с `DiscordLink.exe`. Архив, профили и настройки хранятся в `%LOCALAPPDATA%\DiscordLink`.

## Главное меню

| Клавиша | Действие |
| --- | --- |
| `1` / `2` | Запустить / остановить обработку трафика |
| `3` | Проверить соединения повторно |
| `4` / `5` | Показать / скопировать последний отчёт |
| `6` | Настройки автозапуска, Game Filter и отчётов в Telegram |
| `8` | Свернуть отдельное окно программы в трей |
| `0` | Завершить работу DiscordLink |

После успешного запуска движка консоль на три секунды показывает «Подключено» и возвращается в главное меню. Действия также доступны из меню значка в трее. Консоль автоматически обновляет статус и перерисовывает текущее меню, чтобы старые строки не накапливались. Пункт «Проверить соединение» запускает проверку в фоне, результат доступен через «Диагностика».

**Автозапуск** выключен по умолчанию. Настройка добавляет запись для текущей учётной записи Windows. При входе может появиться обычный запрос UAC. Перед переносом или удалением EXE выключите автозапуск. После переноса включите его заново из новой папки.

**Game Filter** выключен по умолчанию. Пункт 2 в настройках последовательно переключает три режима:

- **Выкл.** Действуют правила Discord и YouTube.
- **Все игры.** Дополнительно обрабатываются начальные TCP- и UDP-пакеты на портах 1024–65535, за исключением 1935.
- **Rainbow Six Siege.** Дополнительно обрабатываются начальные UDP-пакеты на портах 3074, 6015 и 10000–10099, [указанных поддержкой Ubisoft для PC](https://steamcommunity.com/app/359550/discussions/1/1637536330475856676/). Это может затронуть и другие приложения на этих UDP-портах.

Переключение перезапускает активный движок. Для проверки режима Siege перезапустите Ubisoft Connect и игру, затем попробуйте войти в матч. Проверки DiscordLink измеряют соединение с Discord и YouTube. Состояние игровых серверов можно посмотреть [на сайте Ubisoft](https://www.ubisoft.com/en-us/game/rainbow-six/siege/status).

## Подбор профиля и диагностика

Программа пробует сохранённый профиль первым и ищет рабочий вариант для обоих сервисов. Если ни один профиль не прошёл проверки YouTube, программа может оставить рабочий Discord и показать статус YouTube отдельно.

После смены сетевого адреса, маршрута или выхода из сна DiscordLink даёт сети несколько секунд на стабилизацию, затем проверяет подключение. Один сбой Discord запускает повторную проверку. При двух последовательных сбоях программа пробует запасные профили. Успешная проверка сохраняет запущенный движок.

Для Discord проверяются API, WebSocket Gateway, CDN и обновления Windows. Для YouTube проверяются сайт и сервер перенаправления видеопотоков. Проверки подтверждают доступ к этим адресам. Воспроизведение видео, голос и скорость больших загрузок проверяются в самих клиентах.

```powershell
.\DiscordLink.exe -check -samples 5
.\DiscordLink.exe -tune
.\DiscordLink.exe -profile update
.\DiscordLink.exe -tray
```

- `-check` измеряет соединения при текущих настройках сети. Запрашивает манифест Discord и один байт пакета обновления, а также публичные адреса API, Gateway, CDN и YouTube.
- `-tune` проверяет каждый из четырёх профилей. Приоритет у профилей, которые проходят проверки обоих сервисов. Дальше они сортируются по медиане времени самого медленного запроса Discord.
- `-profile` запускает указанный профиль в консоли. Доступны `split`, `update`, `overlap` и `disorder`.
- `-tray` запускает приложение сразу в трее. Этот параметр используется для автозапуска.

## Сборка

Нужен Go 1.24 или новее. Выполните из папки с `go.mod`. В ZIP это папка `source`.

```powershell
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go build -trimpath -o DiscordLink.exe .
```

Команда `go test ./...` запускает тесты выбора профилей, диагностики, WebSocket и Game Filter. Для проверки распаковки движка задайте `DISCORDLINK_TEST_ARCHIVE` с путём к официальному ZIP. Сетевой движок распространяется его авторами через [Flowseal](https://github.com/Flowseal/zapret-discord-youtube) и [zapret](https://github.com/bol-van/zapret).

## Отчёты в Telegram

Отправка включается с согласия пользователя через «Настройки → Отчёты в Telegram». В публичной сборке адрес уже настроен, отдельный файл не нужен. Строка «Отчёт принят сервером» подтверждает приём статуса для сводки. В настройках можно отправить статус вручную. Для настройки собственного бота и Worker см. [инструкцию](relay/README.md).
