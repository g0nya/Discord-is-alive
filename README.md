# DiscordLink

Портативная утилита обхода DPI для Discord. Первая сборка рассчитана на Windows 10/11 x64.

## Запуск

1. Распакуйте ZIP в обычную папку. Если уже запущен другой обход на базе `winws.exe`, остановите его перед запуском.
2. Откройте `DiscordLink.exe` и подтвердите запрос Windows на повышение прав. Эти права нужны WinDivert для работы с сетевыми пакетами.
3. Дождитесь строки `Engine running`. Запустите или перезапустите Discord и проверьте текстовый и голосовой канал. Для остановки нажмите Ctrl+C в окне DiscordLink.

При первом запуске программа скачивает [официальный ZIP Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3). Если загрузка с GitHub недоступна, положите официальный `zapret-discord-youtube-1.10.3.zip` рядом с `DiscordLink.exe` целиком. Перед извлечением программа сверяет SHA-256 архива с опубликованным значением. Временная папка движка содержит только необходимые файлы. Архив и выбранные профили кэшируются в `%LOCALAPPDATA%\DiscordLink`.

## Проверка скорости

```powershell
.\DiscordLink.exe -check -samples 5
.\DiscordLink.exe -tune
.\DiscordLink.exe -profile overlap
```

- `-check` измеряет время ответа публичного API, WebSocket-рукопожатия Gateway и CDN. Для сравнения выполните команду в отдельных сеансах без обхода, с прежней утилитой и с DiscordLink. Сравнивайте медиану нескольких запусков на одной сети. Пока работает один обход, остальные должны быть выключены.
- `-tune` проверяет все три профиля. В каждом раунде три запроса запускаются параллельно. Среди профилей, прошедших все проверки, выбирается профиль с наименьшей медианой времени самого медленного запроса в раунде.
- Обычный запуск проверяет первым профиль, сохранённый для текущего набора сетевых интерфейсов и IPv4-адресов. Если он не подходит, программа перебирает остальные до первого успешного.
- `-profile` включает выбранный профиль вручную. Доступны `split`, `overlap` и `disorder`. Это позволяет, например, проверить голос при недоступности одного из тестовых HTTP-адресов.

Профили меняют TLS и QUIC для списка доменов Discord, а также распознанные начальные UDP-пакеты Discord Voice и STUN в заданных диапазонах портов. Проверка скорости измеряет установление соединений. Голос и передачу файлов нужно проверять в клиенте. Программа рассчитана на фильтрацию DPI, поэтому результат зависит от провайдера и способа блокировки.

## Сборка из исходников

Go 1.24 или новее, внешние Go-модули не требуются. Выполните из папки с `go.mod`. В ZIP это папка `source`.

```powershell
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go build -trimpath -o DiscordLink.exe .
```

`go test ./...` проверяет WebSocket-рукопожатие и подбор профиля. Для проверки извлечения движка задайте `DISCORDLINK_TEST_ARCHIVE` с путём к официальному ZIP. Сетевой движок распространяется его авторами через [Flowseal](https://github.com/Flowseal/zapret-discord-youtube) и [zapret](https://github.com/bol-van/zapret).
